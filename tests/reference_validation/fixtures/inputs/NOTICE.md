# Provenance and license of these test inputs

`usgdp_*`, `nyfed_*` and `brgdp_*` were exported by
`scripts/reference_fixtures/export_inputs.R` from the datasets `USGDP`, `NYFED` and
`BRGDP` bundled with the R package `nowcasting` 1.1.2 (de Valk, de Mattos & Ferreira,
2019), which is distributed under the GPL-3. The underlying series are public
statistics (FRED, BCB, IBGE and the FRBNY Staff Nowcast example files).

- These files are **test inputs only**: they are used by `tests/reference_validation`
  to call the R package as a black box and compare results. They are **not** part of
  the `nowcastbox` wheel or sdist (`tests*` is excluded from the package) and no
  nowcastbox code is derived from them or from the R package's source.
- They are not covered by the MIT license of NowcastBox; redistributors of this
  repository should treat them under the license of their origin (GPL-3 package
  data, public underlying series) or regenerate them with the script above.

`simulated.csv` is generated by `scripts/reference_fixtures/make_simulated.py` (MIT).
